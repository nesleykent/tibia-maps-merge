Icon Names

Type one of these as the last value on a line to give that marker its own icon -- 32250, 31385, 5, Depot, flag. Names are case-insensitive. Anything unrecognised is read as part of the label instead, so it has to match exactly. The byte on the right is what ends up in minimapmarkers.bin.

How It Works

  1. We fetch the latest community markers straight from tibiamaps.io -- the same file it uses for its own map installer, so it's always current with the latest Tibia update.
  2. You upload your own markers -- the minimapmarkers.bin file from your Tibia client's minimap folder (or a markers.json, if you already have one).
  3. We merge them on your device -- markers are matched by their map coordinates. If you and the community both marked the same location, your marker takes priority.
  4. You get a new minimapmarkers.bin, plus a backup of your original markers file and a detailed merge log. Put the new file into that same minimap folder (replacing the old one) and restart your Tibia client.

That's Merge, the first of five tabs. Use Collections to add or remove a published collection, Edit Markers to create your own markers, Convert to switch between BIN and JSON, or Extract to recover your personal markers from a mixed file.
