Tibia Maps Merge

Tibia's map changes with every game update, and tibiamaps.io keeps its community markers updated to match. This merges your personal markers with the latest community ones -- so you get both, with your own winning if you've marked the same spot differently.

How it works

  1. We fetch the latest community markers straight from tibiamaps.io -- the same file it uses for its own map installer, so it's always current with the latest Tibia update.
  2. You upload your own markers -- the minimapmarkers.bin file from your Tibia client's minimap folder (or a markers.json, if you already have one).
  3. We merge them, entirely in your browser -- markers are matched by their map coordinates. If you and the community both marked the same spot, yours wins.
  4. You get a new minimapmarkers.bin back, plus a backup of what you uploaded and a full log of what changed. Drop the new file into that same minimap folder (replacing the old one) and restart your Tibia client.

That's Merge Mode, below. If you just want to convert a file between formats without merging anything -- for manual editing, version control, or other tools -- switch to Conversion Mode. And if you want to type markers in by hand -- coordinates, a label and an icon -- use Add Marks.

Other assistants

Same prompt, sent somewhere other than ChatGPT. It asks the assistant to read the article and return the marks as text; paste that answer into Coordinates when it comes back.

Most of these need you to be signed in to that service, and some shorten a long link. If the prompt arrives incomplete or empty, use Copy prompt and paste it yourself -- that always works.

Icon names

Type one of these as the last value on a line to give that mark its own icon -- 32250, 31385, 5, Depot, flag. Names are case-insensitive. Anything unrecognised is read as part of the label instead, so it has to match exactly. The byte on the right is what ends up in minimapmarkers.bin.
